02 / THE IDEA

Better looking.
But better for the task?

Visual quality and task performance
do not always improve together.

Images in the real world can contain blur, noise, haze, rain, low light, and compression artifacts at the same time. Their types, severities, and composition orders may be unknown to the deployed vision system.

AgenticTDIR turns restoration into a sequential decision process. A lightweight policy proposes specialized restoration experts. A reference-free task-utility estimator checks each tentative transition on a frozen downstream model. An adaptive controller accepts, rejects, rolls back, or terminates.

Evaluated on classification, object detection, and semantic segmentation across eight benchmarks, the framework generalizes to unseen degradation compositions and unseen datasets without test-time fine-tuning.

03 / HOW IT WORKS

Perception–Proposal–Verification–Control Loop

A closed loop around a frozen task model.
Every restoration action is a decision.

  1. 01

    Perception

    Encode the current degradation state using downsampled RGB and DWT sub-bands.

  2. 02

    Proposal

    A lightweight policy ranks candidate restoration experts for the current state.

  3. 03

    Verification

    Estimate each action’s task-utility gain without ground-truth task labels.

  4. 04

    Control

    Accept or reject candidates using an adaptive threshold, with rollback after rejection. Terminate when all candidates are rejected or the step budget is reached.

04 / EXPERIMENTS

See what the experiments reveal.

From benchmark comparisons to real scenes.
Each experiment tests a different part of the idea.

UNSEEN COMPOSITE DEGRADATIONS

Recovering information across vision tasks.

These comparisons test whether restoration recovers the information needed for classification, detection, and segmentation under unseen degradation compositions. The restored images and task predictions show how AgenticTDIR preserves discriminative details across different datasets, with the downstream models kept frozen.

REAL-WORLD GENERALIZATION

Beyond controlled degradations.

These case studies test whether the agent can handle real images with unknown degradations. Fog, snow, and raindrops probe conditions without matched specialists in the expert library; the nighttime scene tests whether composing several experts can recover information for detection in practice.

SUPPLEMENTARY EXAMPLES

More real-world comparisons.

These additional cases test whether restoration recovers task-relevant information across more scenes affected by fog, snow, and raindrops.

More real-world scenesExpand additional classification, detection, and segmentation examples.+

VISUAL QUALITY VS. TASK PERFORMANCE

The details that change a prediction.

This bird classification case tests whether better image quality also means better recognition. AgenticTDIR recovers the discriminative eye detail and the correct class, despite slightly worse PSNR and LPIPS than AgenticIR. The class activation maps illustrate why task-relevant details matter.

POLICY TRANSFER

A policy that works beyond its training model.

This experiment pairs policies and task models across ResNet-50, ViT-B/16, and ConvNeXt-B to test robustness to a different downstream backbone. Every tested pairing improves on degraded inputs. Matched pairs deliver larger gains overall, while mismatched pairs retain useful improvements.

COMPONENT ABLATION

Why proposal, verification, and control work together.

These ablations test what happens when the decision loop is simplified. Removing multiple proposals, adaptive thresholds, or warm-up reduces performance; directly executing the top-ranked action causes the largest average drop. The results support checking and controlling each restoration decision.
